## Voxel Isle

A small, hand-built voxel island that floats in a quiet sky. It has a full day/night cycle, a campfire, a pond and waterfall, drifting clouds, fireflies, birds, and five hidden lumen shards to find.

- **Touch first:** virtual joystick, drag-to-look, jump and sprint buttons, pinch to zoom.
- **Tilt look:** optional accelerometer steering, with the iOS motion-permission prompt handled on a tap.
- **Keyboard:** WASD to move, Shift to sprint, Space to jump, drag or move the mouse to look.
- **No build step:** plain HTML/CSS/ES modules with Three.js vendored locally.

Serve the folder with any static file server and open `index.html`.
